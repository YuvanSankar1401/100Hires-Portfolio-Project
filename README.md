# 100Hires Portfolio Project

## Tools Installed

* Cursor IDE
* Claude Code Extension
* OpenAI Codex CLI
* GitHub

## Steps Completed

1. Installed Cursor IDE and created an account.
2. Connected my GitHub account to Cursor.
3. Installed the Claude Code extension.
4. Installed OpenAI Codex CLI.
5. Logged into Codex using my ChatGPT account.
6. Created a public GitHub repository called **100Hires-Portfolio-Project**.
7. Cloned the repository from GitHub.
8. Opened the repository in Cursor.
9. Created and updated this README file.

## Issues I Faced

### Couldn't Find Claude Code and Codex

When I searched for Claude Code and Codex in the Cursor marketplace, I couldn't find them. Since I was new to Cursor, I wasn't sure if I was searching in the right place or if I was missing something.

**What I did:**

I asked Cursor's AI agent to install Claude Code and Codex. It helped me figure out the installation process and both tools were installed successfully.

### Couldn't Log Into Claude Code

After installing Claude Code, I tried to sign in but found out that it requires a Claude Pro or Max subscription. I only had access to the free version of Claude.

**What I did:**

Since I couldn't complete the login, I noted the issue and moved on to the remaining steps instead of getting stuck.

### Claude Desktop App Was Showing a Blank Screen

I had already installed Claude on my PC before starting this task. When I opened it, I only got a blank screen.

**What I did:**

I checked the browser version of Claude and confirmed that my account was working. Since the web version worked fine, I continued using that.

### Problems Installing Codex

While installing Codex, I ran into SSL certificate errors and some network-related issues. At first I wasn't sure what was causing the problem.

**What I did:**

I tried a few different things and retried the installation multiple times. After some time, the network issue resolved itself and I was able to install and log into Codex successfully.

### GitHub and Cursor Setup

I already knew what Git and GitHub were, but this was my first time creating my own GitHub repository and connecting it with Cursor.

At one point I could see GitHub connected on the Cursor website, but I wasn't sure if it was actually connected inside the application.

**What I did:**

I verified the connection, authorized GitHub access when prompted, cloned the repository, and opened it successfully in Cursor.

### Learning New Tools

Most of these tools were completely new to me, so I had a lot of questions while doing this task.

**What I did:**

Whenever I got stuck, I used ChatGPT for guidance, searched for information when needed, and followed the instructions step by step until I figured things out.
